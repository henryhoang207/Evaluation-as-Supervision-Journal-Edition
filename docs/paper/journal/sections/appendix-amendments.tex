\subsection{Second-model runtime and gates}
\label{app:runtime}
All trials outside the second-model cell used \model{} through Google's
OpenAI-compatible endpoint, at temperature~0 except in the warm cell. Fallback
to a second model was disabled throughout. The second-model cell used
Qwen2.5-7B-Instruct with 7.6 billion parameters, in Q4\_K\_M quantisation
(Ollama model digest \code{d7898812a651}\ldots). Ollama~0.40.3 served it on
one NVIDIA RTX~5060~Ti GPU with 16\,GB of memory, with every layer on the GPU.
Decoding used temperature~0, a fixed seed, a 32{,}768-token context, a
4{,}096-token output cap and one request at a time. The run header records the
full provenance, including tokenizer and executable hashes.


Four gates preceded any final trial: the model fully on the GPU with its
  context loaded (G1); ten real \arm{A1} prompts, sent twice, returning
  identical outputs (G2); every planned prompt fitting the context with a
  4{,}096-token output reserve, any defect that does not being excluded before
  any call (G3); and most first calls schema-valid in a five-defect pilot (G4).
  \arm{A1} and \arm{A2} run at \arm{P1} on every eligible defect and \arm{A3}
  at \arm{P0} on the core's quarter stride, with $r=3$ after G2 failed
  (Section~\ref{sec:design-deviations}) and the first repetition alone as a
  sensitivity.
